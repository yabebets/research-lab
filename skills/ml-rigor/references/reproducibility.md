# 再現性と公開の基準（ML・ロボティクス・フィジカル AI）

論文の結果を、他の人が同じ手順で回し直せるようにするための決まり。主な会議・分野の慣行を、このリポジトリの言葉でまとめたもの（2026-11 時点。投稿する前に、その年の投稿先の要項を必ず読み直す）。

## 下敷きにした慣行
- **NeurIPS の評価とデータの部門**（2026 年に Datasets & Benchmarks から Evaluations & Datasets に改称）：コードは投稿の時点で査読者が実行できる形で公開する（匿名のリポジトリでよい）。データとコードは補足ではなく論文の本体として扱う。新しいデータセットは長く置ける場所（Hugging Face・Harvard Dataverse・Kaggle・OpenML）に置き、Croissant のメタデータを付ける。採択後は公開が条件
- **NeurIPS などの再現性のチェックリスト**：乱数の種、ばらつきの示し方、計算資源、データとコードの公開の有無を答える
- **ACM の成果物の評価（バッジ）**（ICSE などシステム・ソフトウェア工学）：成果物が手に入る・動く・再現できる・再利用できる、を査読者が確かめる。コンテナで固めた環境が強く勧められ、長く再現するには Dockerfile だけでなく作ったイメージそのものを残す
- **ロボティクスのベンチマーク**（SimplerEnv、複数のベンチマークをまとめて評価する仕組みなど）：ベンチマークごとに依存の版を固定した Docker のイメージを配り、版の番号を付ける
- **計算機をまたいだビット単位の一致は前提にしない**：GPU を揃えても CPU が違うとビット単位の一致が崩れ、結果が変わることもある（2026 年の操作のベンチマークの監査）。同じ計算機での回し直しは一致する。だから、計算機を記録し、結果の違いを統計で示す

## チェックリスト（G2 で plan.md に書き、G3・G4 の前に確かめる）

### 環境
- [ ] 評価に使う環境を **コンテナのイメージ**（Docker）に固める。OS・言語の版・全ライブラリの版（ロックファイル）・線形代数の部品（BLAS の種類と版）・スレッド数を固定する
- [ ] イメージの指紋（digest）とタグを、台帳と論文に書く。イメージそのものを残す（Dockerfile だけにしない）
- [ ] シミュレータ・外部の資産（ロボットのモデル・CAD・上流のコード）は commit か sha256 で固定する（`sims.lock.yaml`・`robots.lock.yaml`）
- [ ] 判定・評価の上限は、壁時計の秒ではなく、探す回数・ステップ数で決める（秒は計算機の速さで結果を変える）
- [ ] 乱数の種はすべて設定から決まる。ライブラリの版で変わる乱数の列（scipy の scramble など）に頼らない

### 実行
- [ ] 本番の評価は、固定したイメージを **1 台の計算機** で回し、計算機の種類・CPU・OS・イメージの指紋を各 run に記録する（`rl run` の記録）
- [ ] **別の計算機での回し直し**：本番の結果の一部（層に分けた無作為の抜き取り）を、別の計算機（クラウドの CPU など）で同じイメージで回し直し、食い違いの割合と区間を報告する。食い違いが結論を変えないことを示す
- [ ] 手元の開発と本番で同じイメージを使う（開発の環境と本番の環境がずれない）
- [ ] GPU の学習・シミュレーションは、同じ計算機でもビット単位では一致しないことがある。seed の数と区間で示す（`rl_stats.py`）

### 報告
- [ ] seed の数、ばらつき（区間）、n を全部の表に書く（SKILL.md の統計の決まり）
- [ ] 計算資源：計算機の種類、合計の時間（CPU・GPU）、API の費用
- [ ] 失敗・打ち切り・未決の件数を隠さない
- [ ] チェックリスト（投稿先のもの）に全部答える

### 公開
- [ ] コード：投稿の時点で実行できる形（匿名のリポジトリ）。README に、イメージを取ってきて表を作り直す 1 本の手順を書く
- [ ] データ・注釈：長く置ける場所に置き、メタデータ（Croissant など）とデータの説明書（誰が・何を・どう作ったか、ライセンス、使ってはいけない用途）を付ける
- [ ] 他人の資産（CAD・モデル）は再配布できるかをライセンスで確かめ、できないものは取得元と commit を参照する形で出す
- [ ] 公開（arXiv・リポジトリの公開・データの公開）は人が行う

## 書き方
- 「完全に再現できる」と書かない。「固定したイメージ〈digest〉で、別の計算機で回し直した N 件のうち K 件が一致（区間）」のように、確かめた範囲を書く
