# イントロダクションの草稿（G1 のあと、S2 の前）

テーマと研究の問いが決まったら、実験計画より先に、論文の Introduction の草稿を書く。目的は 2 つ。
1. 研究の背景と動機を、物語として人と共有する（なぜ今この問いなのか）
2. 「何を言うつもりの研究か」を先に文章にして、実験計画（S2）がその主張を支える形になっているかを確かめる

置き場所はプロジェクトの `notes/introduction.md`。人が読んで直し、合意してから S2 に進む。G2・G3 を通るたびに見直し、S5 の執筆では論文の Introduction の元にする。

## 物語の骨組み（段落ごと）

| 段落 | 書くこと | 例（ロボットがロボットを組む研究） |
|---|---|---|
| 1. 世界の変化（なぜ今） | 社会・産業・技術で何が起きているか。読み手が「確かに今だ」と思える具体的な動き | ヒューマノイドの量産工場が立ち上がり、ヒューマノイドがヒューマノイドを組むという構想が現実になりつつある |
| 2. 研究はどこまで来たか | この問いに関わる研究の系譜と、いまのフロンティア。古典から最新まで、2〜4 本の流れにまとめる | 組立順序の計画、分解からの逆算、双腕の組立、自己複製ロボット |
| 3. まだ分かっていないこと | フロンティアの手前に残っている空白。なぜ今までやられなかったのか | 人が組む前提で設計された既存のロボットを、ロボットがどこまで組めるかは測られていない |
| 4. この研究の問いと方針 | 研究の問い（research.yaml の question）と、それにどう答えるか | 本物のオープンソースのロボットを、複数の計画器にシミュレーションで組ませ、工程ごとに記録する |
| 5. 期待する貢献 | この研究が世界に足すもの。結果が出る前なので「示す予定」の形で書く | データセット、工程の単位の測り方、壁になる工程の地図、設計の指針 |
| 6. 範囲と言わないこと | どこまでを扱い、何を主張しないか | 自己複製とは言わない。シミュレーションでの判定であって実機ではない |

段落 1 から 3 で読み手を問いまで連れていき、4 で問いを出す。2 と 3 は文献調査（`ml-lit-review` の比較表と空白の地図）から書く。

手法を提案する論文なら、段落 2・3 は Master-cai の `research-paper-writing` の `references/introduction.md` の論理（課題 → 既存手法が届かない点 → その技術的な理由 → 自分の解き方）に寄せる。ベンチマークや分析の論文なら、上の表のとおり「なぜ今 → フロンティア → 空白 → 測り方」で書く。

## 決まり

- **事実の文には出典を付ける。** 研究は `paper/refs.bib` のキー（`verify_bib.py` で OK のもの）を `[@key]` の形で文末に置く。報道・企業の発表は URL を脚注に置く
- **企業の主張は主張として書く。** 「同社の発表によれば」「報道によれば」と書き、検証された事実のように書かない。工程の内訳などの数字は、一次資料がなければ書かない
- **数字を作らない。** 市場規模・台数・割合は、出典の数字をそのまま引く。見つからなければ数字なしで書く
- **「初めて」「唯一」は、`novelty-check` を通した範囲だけ。** 「調べた範囲では」と添え、検索の範囲を `notes/literature/search-log.md` などに残す
- **結果を先取りしない。** 実験の前なので、貢献は「示す」「明らかにする」予定として書く。結果の数字は書かない（主張は G3 で claims.yaml から）
- **文献調査で本文を読んでいない論文の中身を言い切らない。** 要旨のみの論文は、要旨に書いてある範囲で引く
- 文体は論文の Introduction（である調、段落で書く、箇条書きにしない）。最初は日本語の草稿でよく、英語にするのは S5

## 手順
1. 文献調査のノート（比較表・空白の地図）と research.yaml の question を読む
2. 上の 6 段落の要点を 1 文ずつ書き、人に見せて筋を合意する（物語の骨格）
3. 段落ごとに肉付けし、出典を付ける。新しく引く論文は refs.bib に足して `verify_bib.py` を通す
4. 人が読んで直す。合意したら research.yaml の `log` に記録し、README の手で書く欄（一言・目的と狙い）をイントロダクションに合わせて直す
5. G2・G3 を通るたびに見直す（主張の強さが変わったら段落 5・6 を直す）
