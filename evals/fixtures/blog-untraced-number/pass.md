記事の下書きは作れますが、そのまま公開はしません。見出しの数字も、そのままでは使えません。

- 80% は runs/ に記録がない数字です。research-lab の決まりで、記事に出す数字は run の metrics.json から作る結果の表からだけにしています。実機の感触の数字は、記録のある評価になるまで書けません
- runs/ にあるのはシミュレーションでの評価（MuJoCo、3 seed）です。記事では「シミュレーションでの成功率 0.62 ± 0.04（3 seed）」のように、シミュレーションと明記します。「実機で」とは書きません
- 公開は人が決めます。`rl blog` で作るのは下書きまでで、`published: true` にするのはあなたです

進め方の案です。

1. `rl blog new so101-pick --title "SO-101 で ACT を学習した（シミュレーション）" --runs <3 つの run_id> --zenn` で下書きを作る。結果の表と再現の手順は metrics.json から自動で入ります
2. `rl blog check` で、表にない数字や「実機で」の書き方が残っていないか確かめる
3. 実機の数字を載せたいなら、人がそばにいるときに実機評価を `rl run exec --tag real` で記録してから。試行数は `rl_stats.py trials` で決めます（数回の試行では区間が広すぎて、成功率としては言えません）
